# ChinaGCC

中国现成产品面向GCC（海湾合作委员会）市场的真实需求、合规及利润验证项目。

## 当前方向（2026-10-16）

**先做非翰林商品真实销售成绩，再考虑联系翰林生物。** 用户已明确暂停翰林全部商品的当期推进，冻结研究，不占用厂家/亲属资源，不进行外联、采购、授权谈判。

**010最新主线**：把“非翰林自有SKU真实销售”与“借助Noon Affiliate推广现售商品验证GCC获客”拆成两条不能混同的轨道。Noon中国NGS仍有中国个体户审核、沙特商品归类、买家端价格/ETA和美元跨币种收款门槛等P0，暂停重复选品报告；Noon联盟官方存在且可免费申请，最多10%佣金，但**中国申请人资格、银行收款和开票尚未验证**。eBay官方将中国列为可注册卖家地址地区并区分个人和企业账户，作为跨境零星小额销售的合规候选，但出口物流、支付审核和真实GCC需求仍未解决。**联盟归因佣金不是自有产品交易成绩，不能用来恢复翰林**。不注册主体、不采购、不投广告、不做任何外联或营销发布。

## 执行约束

1. 每一项市场信号须区分“平台已有他人销量”与“我们有订单”；严禁把预测当成绩。
2. 每次只验证一个市场和一个SKU的可销售性；不因已有市场报告就大批量采购。
3. 在Noon中国个体工商户资格、商品归类/合规及消费者最终展示价未确认前，不将经济模型标为盈利。
4. 若无用户后续明确授权，**不主动联系翰林**；至少先完成另一个非翰林SKU真实付款、妥投、结算及全成本复核，再讨论重新启用。
5. 本仓库保留事实与证据；仅以产品合法销售及真实收款衡量阶段进度。
