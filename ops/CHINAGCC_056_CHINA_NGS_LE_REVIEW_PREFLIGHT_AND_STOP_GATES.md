| 阶段 | 平台公开步骤 | 当前工作状态及安全动作 |
|---|---|---|
| A Store | UAE（中国NGS官方全流程另列KSA）店创建 | **UAE GCC Picks已存在**；不重复建店，KSA并未验证创建 |
| B 商业登记 | License number、Registered name、Address、Issue/Expiry date、Commercial Registration文件；Activities可选 | **工作区真实LE字段已读**，无可信资料可填；官方要求文件，不能用空值生成看似真实LE |
| C Entity初建 | 填商登文件后点Continue可产生LE记录 | **即使创建记录也不能立即正式提交审核**（官方专项原文明确） |
| D 税务细节 | 中国NGS专页指定目标国`Non VAT Registered` | 目的国Non-VAT不等于中国本土免税/出口合规豁免；无需此时创建本地UAE VAT实体 |
| E 代表人 | 企业实际代表／授权签字人、真实联系方式与身份材料；非真实持有人需POA | **不能冒用他人主体、身份证或代签**；只可准备材料清单 |
| F 条款签署 | 系统发T&Cs邮件给授权代表，由其依法审阅签署 | **触发邮件和签署为写入/法律行动，未获本轮授权，不操作** |
| G 提交批准 | 全部项目齐备后`Submit Legal Entity for Approval`；等待审核状态 | **当前Required，不是Rejected、不是Pending、不是Approved**；不得用创建记录/Skip冒充批准 |
| H Approval后关联 | 审批后可能需要挂到Store与Origin，Payout获批且实际Origin匹配 | 此处仍未验，无法据前台Store创建推定NGS与回款可用 |

**真实账号观察与一般文章分开**：[049Work实际China LE Add Details](../research/2026-10-31/CHINAGCC_049_UAE_STORE_CREATION_AND_NONPUBLIC_PRODUCT_FORM_TEST.md)显示License Number、Company Name、Address、Issue Date、Commercial Registration文件为必填，Expiry Date及Activities有Optional提示，接受PDF/PNG/JPEG≤10MB；这是本次原账号字段原文。官方中国NGS总览例子把Expiry Date列为需要填写信息，**不能未经真实表单将其一律设成硬必填或随意构造到期日**。

## 3. 两处官方材料冲突，不得选对自己有利的答案

### 3.1 营业登记剩余有效期：15天 vs 30天

- [官方Who can sell](https://helpcenter.noon.partners/en/category/onboarding-and-registration/who-can-sell-on-noon)以及[Required documents](https://helpcenter.noon.partners/en/category/onboarding-and-registration/documents-required-to-sell-on-noon)写提交时剩余有效期**至少15天**。
- [官方Understanding application rejection reasons](https://helpcenter.noon.partners/en/category/onboarding-and-registration/understanding-the-application-rejections-reason-and-how-to-resolve-them)的拒绝原因表写**至少30天**。
- 没有官方明确写哪一条对**新中国NGS LE、无固定终止期限的中国营业执照**优先。**建议**有明确到期日者在提交前保持明显超过30天的余量；这仅是保守风控，**不声称官方已在本账号固定30天**。无限期执照需按其证照实际格式、当前表单处理，不能编造`Expiry Date`。

### 3.2 中国居民身份证 vs 国际卖家Passport

- [官方Required documents](https://helpcenter.noon.partners/en/category/onboarding-and-registration/documents-required-to-sell-on-noon)国际卖家表格写代表人**Passport**。
- [官方拒绝原因指南](https://helpcenter.noon.partners/en/category/onboarding-and-registration/understanding-the-application-rejections-reason-and-how-to-resolve-them)却在可接受的身份文件清单中包含**Chinese resident ID**。
- 二者一般政策互有差异；**不能声称中国NGS一定只要身份证、也不能声称中国公民绝对必须护照**。只读官方可证的结论是该类证件在不同Noon官方文件中都被提及；**实际China NGS LE表单可选择的文件类型/审核结果未被Work新读到**。未来进入证件上传之前，先由已授权Work只读表单支持哪些类型，保留截图/文字；无真实材料及用户授权不提交。

### 3.3 个体工商户/个人独资企业/一人有限公司

- [中国NGS专项](https://helpcenter.noon.partners/en/category/global-selling/noon-global-shipping-program)只写`valid Chinese Commercial Registration`；
- 一般国际卖家材料称`Company registered anywhere`；埃及`Individual Seller`不等同持合法中国个体工商户营业执照；
- 中国个体户和个人独资是否可被**China NGS专用LE**认可仍`UNKNOWN`；一人有限公司虽更符合“公司”一般文字，但也未实际自动通过。本轮没有出现该主体分类的真实后台批准或Noon专项YES/NO。
- 不替用户先办有限公司，不借他人营业执照碰运气，更不能填模拟公司名让系统过关。

## 4. 通用Rejected/Needs attention的准确含义（不能归因本账号）

[官方审核驳回与修复指南](https://helpcenter.noon.partners/en/category/onboarding-and-registration/understanding-the-application-rejections-reason-and-how-to-resolve-them)区分：
- `Rejected`：已提交的LE被拒，不能正式销售；常见为文件非正式营业登记、信息不完全吻合、经营范围仅服务、扫描裁剪/真实性问题、重复执照号、代表人身份或POA不匹配。
- `Needs attention`：常见已批准账号的收款资料未绑定Origin、收款名称不一致、执照过期等；可能停止打款，但不一定停止原来已活跃的销售。
- **本项目真实状态是`Required/NOT_SUBMITTED`**，没有Rejected状态及拒绝原因；NGS Programs无资格提示亦没有独立对应的拒绝原因。**不能凭一般失败原因名单给本账号自动诊断出缺哪张证件。**

1. **已完成**：Store存在；Work能以合法已登录账号看到Setup Guide与China LE必填表单；本轮完成官方一手规则、两项相互矛盾字段和审核状态的核验。
2. **可做且不需新增注册/外联**：仅通过当前已授权公开资料把真实主体资格和所需材料核成单据清单；允许Work以后在其现有合法任务/无需提交的界面**只读**确认真实证件类型枚举、是否确有审批错误原文，不重开无资格NGS空页；不读取/保存/传递个人身份证号、护照号、银行账号、完整Store ID到公开GitHub。
3. **目前无法真正解除**：若没有一个可合法使用、且Noon愿意批准的中国Commercial Registration，且用户仍禁止注册/上传任何证件、法律签约，那么LE不能获批，China NGS真实开卖必须保持HOLD。已有店铺只是配置准备；重复研究、对商品资料先做许多轮、再点Skip都不会获得LE审批。
4. **明确独立风险**：鸿良 `986877044 / 9336541278` 的图片商业使用权仍`NOT_VERIFIED`；就算将来LE成功也不能以义乌购/1688 CDN图片无授权上架。另要核Seller Lab实际类目是否要求采购凭证/品牌授权，不能预先编造发票。 
5. **立即停止点**：合同签字、触发T&C邮件、上传商业登记或个人证件、绑银行、创建假SKU/库存/报价、激活售卖或自动外联皆不在本轮授权范围。

**决策**：`GO_LE_PREFLIGHT_DOCUMENT_REQUIREMENTS_VERIFIED`；`NO_GO_LE_APPROVAL_WITHOUT_AUTHENTIC_DOCUMENTS`；`NO_GO_NGS_LIVE`。**实际下一关**：经用户拥有真实合法主体并允许正式提交后，方可审查其具体营业登记、代表人权限及收款身份，走平台合法审批；如果仍不允许，保留HOLD而不制造同义任务。不存在“不注册、不提交合法资料，但让平台正式批准中国LE”的已经证实的方法。
